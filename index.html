PeachyTube

Play YouTube in any key, mute or pan each instrument (vocals, guitar, drums, bass, piano), and record yourself along with it.

Download for Android
  1. Tap Download for Android and open the downloaded file.
  2. If Android asks, allow your browser to install unknown apps, then tap Install (on a Play Protect warning: More details → Install anyway).
  3. Later versions arrive in the app itself (menu → Check for updates).
